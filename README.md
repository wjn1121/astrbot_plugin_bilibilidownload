# 📺 B站视频下载 — AstrBot 插件

> 群友丢一个 B 站视频链接，机器人自动解析视频信息、用 AI 给出几句总结，并按需把视频文件下载并发到群里。

## ⚡ 快速开始

1. **安装插件**：在 AstrBot WebUI 插件市场中搜索「B站视频下载」一键安装，或手动放入 `data/plugins/astrbot_plugin_bilibilidownload/`
2. **安装依赖**：WebUI → 插件管理 → B站视频下载 → 点击「安装依赖」按钮（`aiohttp`，AstrBot 本体通常已自带）
3. **直接使用**：在群里发一条 B 站视频链接，机器人回复解析信息 + AI 总结

```
群友: https://www.bilibili.com/video/BV1dwYE68ED2
Bot:  🔍 正在解析视频信息…
Bot:  📺 倒霉糯：吃饭的路如此艰难吗？
      👤 玖梦sky丶 · 2分11秒 · 12.8万播放

      📝 AI 总结（基于简介与热评）
      这是 UP 主「倒霉糯」系列的日常向短片……

      🔗 下载页：https://www.ebilibili.com/video/BV1dwYE68ED2
      💡 回复「下载」或发送 /bdl 可获取视频文件
群友: 下载
Bot:  ⬇️ 正在下载《倒霉糯：吃饭的路如此艰难吗？》…
Bot:  📺 倒霉糯：吃饭的路如此艰难吗？
      👤 玖梦sky丶 · 2分11秒 · 12.8万播放

      🎬 视频文件已附在下方
Bot:  [视频]
```

## ✨ 功能特性

- 🔗 **链接自动识别**：`BV号`、`av号`、`bilibili.com/video/...` 完整链接、`b23.tv` 短链，支持 `?p=2` 分P参数，无需唤醒词
- 📋 **视频解析**：标题、UP 主、时长、播放量、分P信息，数据来自 B 站公开接口（**无需登录、无需 Cookie**）
- 🧠 **AI 总结**：调用当前会话的大模型生成 3~5 句总结，并在回复中**注明总结依据**，信息不足时如实说明而不编造
- ⬇️ **按需下载**：默认只发解析 + 总结；回复「下载」或发送 `/bdl` 才下载视频文件（也可以在面板打开「自动发送视频文件」）
- 🔀 **两种发送方式**：本地文件 / 直链 URL，`auto` 模式下本地文件发送失败会**自动改用直链**，兼容协议端与 AstrBot 分离部署（Docker）的环境
- 🪜 **四级降级**：直链接口 → 表单页 → 解析页 → 回复网页链接，下载站抽风也不会「已读不回」
- 🛡️ **多重防刷屏**：单用户冷却、同视频并发去重、群白名单、触发范围限定
- 📉 **体积保护**：下载前用 `HEAD` 预检体积，超限直接改发链接，不会先下几百 MB 再放弃
- 🧹 **自动清理**：临时文件在发送完成后删除，另有 24 小时残留兜底清理

## 🚀 使用方法

| 操作 | 效果 |
|------|------|
| 发送 B 站链接 / BV号 | 回复解析信息 + AI 总结（面板开启「自动发送视频文件」时同时发视频） |
| 回复「下载」 | 下载本会话最近解析过的视频（30 分钟内有效） |
| `/bdl` | 同上，下载最近解析过的视频 |
| `/bdl <链接或BV号>` | 直接解析并下载指定视频 |

> 💡 AstrBot 默认命令前缀为 `/`，如果你改过前缀，`/bdl` 也要相应调整。
> 「下载」关键词只在**本会话刚解析过视频**时才响应，其他时候会正常交给 LLM 对话，不会抢话。

## ⚙️ 配置项

在 AstrBot WebUI → 插件配置面板中可调：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `trigger_scope` | 下拉 | `group` | 触发范围：仅群聊 / 仅私聊 / 两者 |
| `need_at_in_group` | 开关 | `false` | 群聊中是否必须 @机器人 才自动解析，防群里刷屏 |
| `send_video` | 开关 | `false` | **是否自动发送视频文件**；关闭时靠「下载」/`/bdl` 按需触发 |
| `video_send_mode` | 下拉 | `auto` | 视频发送方式：自动（失败降级直链）/ 仅本地文件 / 仅直链 URL |
| `max_video_mb` | 整数 | `50` | 视频体积上限（MB），超限不发文件、改发链接 |
| `enable_summary` | 开关 | `true` | 是否启用 AI 总结；未配置大模型时自动跳过 |
| `summary_max_chars` | 整数 | `200` | AI 总结字数上限，超出截断 |
| `summary_timeout` | 整数 | `45` | AI 总结超时（秒），超时跳过总结，避免群里长时间无响应 |
| `reply_limit` | 整数 | `10` | 取多少条热门评论作为总结参考；填 `0` 则只依据标题与简介 |
| `request_timeout` | 整数 | `20` | 网络请求超时（秒），下载站偶尔响应慢，建议不低于 15 |
| `max_concurrent` | 整数 | `1` | 同时进行的下载任务数，建议 1~2 |
| `user_cooldown` | 整数 | `60` | 单用户触发冷却（秒），防刷屏；填 `0` 关闭 |
| `group_whitelist` | 列表 | `[]` | 群白名单，留空表示所有群生效 |
| `send_ebilibili_link` | 开关 | `true` | 回复中是否附上 ebilibili 网页下载链接 |
| `verbose_log` | 开关 | `false` | 详细日志：输出降级原因、下载进度、耗时，排查问题时开启 |

## 🧠 AI 总结说明

总结由 AstrBot **当前会话使用的对话模型**生成，因此需要先在 AstrBot 里配置好模型（未配置或调用失败时会自动跳过，不影响解析与下载）。

总结依据分两层，插件会在回复里明确标注，不假装「看过」视频：

| 层级 | 输入 | 何时使用 |
|------|------|----------|
| L1 | 标题 + UP主 + 时长 + 分区 + 简介 + 播放/点赞数 | 始终可用 |
| L2 | L1 + 热门评论 Top N | 评论接口可用时（默认开启，`reply_limit=10`） |

> ⚠️ B 站字幕接口需要登录态（`SESSDATA`），因此**当前版本不基于字幕总结**，属于「省流式」概览。
> Prompt 已明确要求模型「信息不足就如实说明」，不会虚构视频情节。字幕增强计划在后续版本支持。

## 📦 视频从哪里下载

视频下载能力依赖第三方站点 [ebilibili.com](https://www.ebilibili.com/download)（把 `bilibili.com` 改成 `ebilibili.com` 即可下载对应视频的那个站）。插件按以下顺序尝试，前一步失败自动进入下一步：

| 顺序 | 方式 | 说明 |
|:---:|------|------|
| 1 | `GET /api/playurl/{bvid}/{cid}` | 直链接口，返回 B 站 CDN（`bilivideo.com`）的 MP4 直链 |
| 2 | `POST /download`（表单 `bvid`） | 从返回 HTML 中提取 `startDownload(...)` 的直链 |
| 3 | `POST /downloads`（表单 `url`） | 新解析页，支持 B站/抖音/快手/小红书 |
| 4 | 回复网页链接 | 以上全失败时，回复 `https://www.ebilibili.com/video/{bvid}` 让用户自行下载 |

注意事项：

- 直链带有效期（`deadline` 参数），插件拿到后会立即下载，不会缓存复用
- 该站是**个人小站、无可用性保证**，接口可能随时变更；插件对网络抖动做了重试与退避，但仍可能失败，此时会明确提示而不是静默失败
- 直链来自 B 站 CDN，下载时须带浏览器 UA（B 站 CDN 会对非浏览器 UA 返回 403），插件已统一处理

## 🔧 技术特点

- **被动正则匹配**：`@filter.regex(...)` 识别链接，无需唤醒词；非 B 站消息完全不响应
- **纯异步**：`aiohttp` + `asyncio`，下载流式写盘，不阻塞事件循环
- **发送后清理**：所有发送 `await` 完成后才删除临时文件——早期版本在生成器 `finally` 中删除，会在 AstrBot 真正发送前把文件删掉，导致协议端报 `retcode 1200 路径不存在`（详见 [DESIGN.md](DESIGN.md)）
- **发送方式自愈**：本地文件发送失败时自动改用直链，适配协议端与 AstrBot 不在同一文件系统的部署
- **文本与视频分开发送**：避免「长文本 + 视频」的混合消息链被包装成合并转发，规避各协议端对转发消息中视频段的兼容差异
- **体积预检**：`HEAD` 拿到 `Content-Length` 即判断，超限不落盘
- **状态防抖**：用户冷却、同链接处理中标记（带时间戳自动过期，不会永久卡死）
- **错误隔离**：解析失败、总结失败、下载失败、发送失败都被隔离处理，单条消息出错不影响插件整体

## ❓ FAQ

**Q：为什么只发了文字，没有视频文件？**

A：默认不自动发视频（避免流量消耗与平台风控）。可以在面板打开「自动发送视频文件」，或回复「下载」、发送 `/bdl` 按需获取。

**Q：日志报 `retcode 1200`「路径不存在」，视频发不出去？**

A：协议端（NapCat / LLOneBot 等）读不到 AstrBot 本地的文件，常见于协议端与 AstrBot 分处不同容器/主机（Docker 分离部署）。插件默认的「自动」模式会在本地文件发送失败后自动改用直链；也可以直接把「视频发送方式」设为**仅直链 URL**，此时插件完全不落盘，把 ebilibili 直链交给协议端自己拉取，省磁盘也省中转流量。

**Q：提示「视频约 N MB，超过体积上限」？**

A：把「视频体积上限 (MB)」调大，或直接点回复里的 ebilibili 链接自行下载。注意 QQ 群对单文件体积有实际限制，过大的文件即使发出也可能失败。

**Q：一直提示下载失败？**

A：说明 ebilibili 四条路径都没走通（站点限速、接口变更或网络受限）。可稍后重试、直接访问回复里的网页链接，或打开「详细日志」看具体是哪一步失败。这类第三方站点无法保证长期可用，插件已尽力降级。

**Q：AI 总结不准 / 没有总结？**

A：未配置大模型、总结超时或调用失败时会自动跳过。另外当前版本**拿不到 B 站字幕**，总结只能基于标题、简介与热门评论，属于概览性质，不代表视频完整内容——这是刻意的诚实取舍，而非 bug。

**Q：会消耗很多流量或磁盘吗？**

A：默认模式（不自动发视频）只做解析和文本总结，流量极小。下载视频时才产生流量，且临时文件在发送后立即删除。「仅直链 URL」模式下机器人完全不下载视频，流量由协议端承担。

**Q：私聊可以用吗？**

A：可以，把「触发范围」改为「群聊和私聊」或「仅私聊」即可。

**Q：分P视频下载的是哪一P？**

A：链接里带 `?p=2` 就下载第 2P，卡片上会标注「（P2）」；不带 `p` 参数则下载第 1P。`p` 超出范围时按第 1P 处理。

**Q：会不会导致 B 站封号？**

A：插件只调用**公开且无需登录**的接口（视频信息、热门评论），不登录、不携带任何 Cookie、不涉及账号操作；同时对下载做了并发限制与冷却。请勿修改代码进行高频抓取。
